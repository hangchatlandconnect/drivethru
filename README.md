# Drive-Thru — สำนักงานที่ดินจังหวัดลำปาง สาขาห้างฉัตร

- `index.html` — **กระดานคิว** วันนี้และวันถัดไปที่มีคนจอง (เลขคิว เวลา สถานะ — ไม่มีข้อมูลส่วนบุคคล รีเฟรชทุก 30 วิ) + ฟอร์มจองคิว → ได้ **ลำดับคิว** และรหัสจอง `DT0001`, `DT0002`, … (เรียงต่อกันทั้งระบบ)
- ลำดับคิวนับต่อวันเริ่ม 1 รวมจองออนไลน์และหน้างาน (คอลัมน์ N `ลำดับคิว` ในชีต)
- `staff.html` — เจ้าหน้าที่: รายการรายวัน · สรุปจำนวนตามสถานะ · ปุ่มสถานะแต่ละคิว รอ / อยู่ระหว่างดำเนินการ / ดำเนินการเสร็จสิ้น / ยกเลิก (กดแล้วบันทึกทันที) · หมายเหตุ · บันทึกรับเรื่องหน้างาน · รีเฟรชเองทุก 1 นาที
- ข้อมูลเก็บใน Google Sheet ผ่าน Apps Script (`apps-script/Code.gs`) — หน้าเว็บวางบน GitHub Pages

ยังไม่ได้ตั้ง `SCRIPT_URL` ใน `js/common.js` = **โหมดตัวอย่าง** ข้อมูลเก็บในเบราว์เซอร์เครื่องนั้นเท่านั้น

## ติดตั้ง (ครั้งเดียว)
1. เปิดชีต → **ส่วนขยาย → Apps Script** → วางเนื้อหา `apps-script/Code.gs` ทั้งไฟล์ → บันทึก
2. เลือกฟังก์ชัน `setup` → **เรียกใช้** (ครั้งแรกจะขอสิทธิ์ ให้อนุญาต) → ใส่หัวคอลัมน์ในแท็บ **Drive-Thru** (6 คอลัมน์แรกคงชื่อเดิม) และสร้างแท็บ **ตั้งค่า** (แท็บ อ้างอิง ไม่ถูกแตะ)
3. ในฟังก์ชัน `setPassword` ใส่รหัสใน `NEW_PASSWORD` → **เรียกใช้** → **ลบรหัสออกจากโค้ดทันที** แล้วบันทึก
4. **การทำให้ใช้งานได้ → การทำให้ใช้งานได้รายการใหม่ → เว็บแอป** · เรียกใช้ในฐานะ: **ฉัน** · ผู้มีสิทธิ์เข้าถึง: **ทุกคน** → คัดลอก URL ที่ลงท้าย `/exec`
5. ใส่ URL นั้นใน `SCRIPT_URL` ของ `js/common.js` → commit/push

แก้ `Code.gs` ภายหลัง: **การทำให้ใช้งานได้ → จัดการ → แก้ไข → เวอร์ชันใหม่** ไม่อย่างนั้น URL เดิมยังรันโค้ดเก่า

## ปรับตั้งค่าในชีต "ตั้งค่า"
| key | ความหมาย |
|---|---|
| services | รายการบริการ บรรทัดละ 1 · บรรทัดขึ้นต้น `#` = ชื่อหมวด · `อื่นๆ` = ผู้จองต้องพิมพ์ระบุ (บันทึกเป็น `อื่นๆ: ...`) |
| slots | ช่วงเวลารับจอง บรรทัดละ 1 |
| perSlot | รับจองได้กี่คันต่อช่วงเวลา (นับเฉพาะจองออนไลน์) |
| daysAhead | จองล่วงหน้าได้กี่วัน |
| closedDates | วันหยุดราชการ `2026-12-05` บรรทัดละวัน (ส.–อา. ปิดอยู่แล้ว) |

## ความปลอดภัย / ข้อมูลส่วนบุคคล
- หน้าสาธารณะอ่านได้แค่ตั้งค่าและ **จำนวน** คิวที่จองแล้ว — ชื่อ/เบอร์/ทะเบียน อ่านได้เฉพาะเจ้าหน้าที่ที่เข้าสู่ระบบ (token 8 ชม.)
- รหัสผ่านเก็บเป็น hash ใน Script Properties · ใส่รหัสผิด 5 ครั้งใน 15 นาที → ล็อก 15 นาที
- กันจองซ้ำ: เบอร์เดียวจองได้วันละ 1 คิว · ช่วงเต็มจองไม่ได้ · ทั้งระบบรับไม่เกิน 20 คำขอ/นาที · มีช่องกับดักบอต
- ข้อความที่ขึ้นต้นด้วย `= + - @` ถูกเก็บเป็นข้อความ ไม่กลายเป็นสูตรในชีต
- อย่าแชร์ชีตเป็น "ทุกคนที่มีลิงก์" — มีข้อมูลส่วนบุคคลของผู้รับบริการ
